# Tone Guide — Empathy First

PR 色を排除し「自分の体験談」として読める縦動画のトーン規範。

## Contents
- やる: 一人称・気付き・等身大
- 避ける: 宣言型・煽り・第三者目線の解決アピール
- caption pattern マッピング
- voice/caption の表記揃え

## やる (○)

- 一人称「私」「俺」「自分」で始まる体験談
- 「思ってた」「だった」「気付いた」「ちょっと変わった」のような気付き・転換
- 二段構成: 「最初の認識」 → 「今の気付き」
- 短い文、口語、余白を残す
- caption は 1 行 5〜8 字を 2 行帯
- 上吹き出しに 8〜12 字の短い独白 (グレー帯)

## 避ける (×)

- 宣言型「◯◯で解決!」「◯◯で落ち着いた」(ブランド名 + 状態変化動詞のセット)
- 煽り「3 社辞めた」「絶対」「全員」「みんな」
- ハッシュタグ風メリット羅列 (#寮完備 #未経験OK)
- 第三者目線「あなたに合う◯◯」「◯◯ならこれ」
- 直接 CTA「ぜひ」「お試しください」「ご検討ください」「無料相談」
- ブランド名や商品名を caption 本文に書く (バッジ・ロゴで別途差し込みもしない)

## Caption pattern マッピング

| 構造 | 例 (テンプレ、案件文言は別途差し替え) |
|---|---|
| 認識 + 補足 | 「[領域]って、／[ネガ印象]って思ってた。」 |
| 気付き + 一人称 | 「でも今の私には、／[領域]がけっこう合ってる。」 |
| 仕組み + 主観 | 「[時間/環境]が決まってるから、／[生活面]は作りやすい。」 |
| 距離感 + 救い | 「[困り事]の時、／[自分軸の対処]でもいい。」 |

文言そのものはプロジェクトごとに別案を作る。テンプレ流用ではなく構造だけ参考にする。

## voice / caption 表記揃え (アクセント安定化)

ElevenLabs 日本語 voice はひらがなだと頭高アクセントになりやすい。原則:

- voice_text と caption_main は **同一語彙を使う**
- 漢字優先 (例: 「こうじょう」→「工場」、「しごと」→「仕事」)
- caption が漢字なのに voice がひらがな、は禁止 (lint_recipe.py 検出)
